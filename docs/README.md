# docs/

Seven PDFs. Six of them are Iskra-226 documentation, one is a Western
datasheet that is here for context. Below is what each file is, in full
bibliographic form, and where the copy in this directory came from.

Everything here is somebody else's work. I mirror it because the links go
dead. See LICENSE-DOCS.

---

## ISKRA-226ArchitectureSoftwareRefMan.pdf

**Персональный компьютер «Искра-226». Архитектура и программное
обеспечение. Справочное руководство**
*Personal Computer Iskra-226. Architecture and Software. A Reference Guide*

- Authors: V. Z. Aladiev, Martynenko and Shilenko, under the general
  editorship of Shilenko
- 1988, Kiev, Main Editorial Office of the Ukrainian Soviet Encyclopedia
- 156 pages in the scan, 152 in the book, print run 50,000, 70 kopeks
- Origin: mirrored from Jim Battle's collection at wang2200.org

The only reference that describes the processor from the inside:
registers, memory areas, the instruction classes, and worked encodings of
single instructions.

## Microcomputer_Programming_for_Iskra-226-ocr.pdf

**Программирование на микроЭВМ «Искра 226»**
*Programming the Iskra 226 Microcomputer*

- Authors: V. E. Balasanian, S. V. Bogdyukevich, V. A. Shakhverdov
- 1987, Moscow, Finansy i statistika
- 171 pages
- Origin: a digital setting of the full text, not a page scan. It comes
  from computer-museum.ru and is mirrored in Jim Battle's collection at
  wang2200.org.

The programming textbook: the four parts of the central block, how the
machine is prepared and where the interpreter comes from at power on, and
BASIC with its Iskra specific statements and worked examples.

### computer-museum-iskra226.pdf

The same document, kept because it is the earlier save. Both files run to
171 pages, hold the same thirty five figures and the same 501,746
characters of text, and every page renders identically. Only the file
properties differ: that one is the 2014 save with the Russian fields still
on it, the one above is a 2020 re-save with English cataloging. They are
not byte identical and they are not two books.

## ISKRA-226_Technical_Information.pdf

**Программоуправляемая электронная клавишная вычислительная машина
«Искра-226». Блок интерфейсный функциональный «Искра 015-85». Паспорт
3.055.210 ПС**
*Factory documentation: the Iskra 015-85 functional interface block,
passport 3.055.210, and further block descriptions*

- No author named. Factory documentation.
- 1982
- 48 pages
- Origin: mirrored from Jim Battle's collection at wang2200.org

Photographs of factory paper: the passport of the interface block, hand
drawn wiring and structural schematics for the display block BOSGI-1920 and
the keyboard interface, pin lists, and a table of how many blocks go into
which configuration.

## intel-3001-mcu.pdf

*Intel 3001 Microprogram Control Unit, Schottky Bipolar LSI Microcomputer
Set*

- Intel Corporation
- 1975
- 14 pages
- Origin: Intel Corporation, 1975, print code MCS-268-0275. The file
  properties carry the title of an unrelated conference paper, which is
  what happens when somebody reuses a template; the pages are the
  datasheet.

The Western datasheet for the sequencer of the Intel 3000 bipolar family:
microprogram address register, jump and test functions, flag control, 40
pin package. Not an Iskra manual. The K589 parts this processor is built
from are Soviet copies of the Intel 3000 family, and this is the only
English description of that layer. It documents the Intel part. Whether an
Iskra board carries the Soviet copy of this particular chip, I cannot show.
